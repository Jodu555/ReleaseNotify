# ReleaseNotify

This is a simple Project that once invoked watches for changes and notifies the user of them.

## Usage

The intended Usage for this is to be just put onto any server and invoked via the Server's
own crontab.

## Example Utility

- If you really enjoy a Github Project and want to be kept updated on those releases

## Currently Implemented Watchers

- [Github Releases](https://github.com)

## Currently Implemented Notification Backend

- [Gotify](https://gotify.net/)
